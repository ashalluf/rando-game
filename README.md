# historic-core stills (wt/historic-core)

Downtown's historic core: beaux-arts banks and offices on Spring St and Main St (2nd to 9th St).
opengl3 (Compatibility) renders; "before" are city stills (still_shot.gd), "after" first batch are
block_shot.tscn renders of the same streets (the FULL blocks alone; no far city past them).

- 01_before_spring_north_noon.jpg - Spring St north from 6th, before (EYE 3113,1.7,60,0,6)
- 02_before_spring_east_face_noon.jpg - the east side of Spring St, before (glass curtain walls)
- 03_before_main_south_noon.jpg - Main St south, before
- 04_after_spring_corner_noon.jpg - Spring St at 7th: rusticated bases, arched first floor, fluted giant order, cornices
- 05_after_spring_north_noon.jpg - Spring St north: base / shaft / capital office blocks, terracotta and brick
- 06_after_main_corner_noon.jpg - Main St corner block: cornice mitred round the corner, attic panels
- 07_after_entrance_noon.jpg - a lit entrance: columns, name block, segmental pediment, bronze lanterns
- 08_after_cornice_from_below.jpg - looking up: modillions, dentils, arches with keystones and fanlights, shaft surrounds
- 09_after_entrance_night.jpg - the same entrance at night (crude block_shot night: lamps on, base floodlit)
- 10_after_spring_corner_night.jpg - Spring St corner at night
