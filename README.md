# shots/mac-verify-pack

The verify pack (docs/VERIFY.md on wt/mac-verify-pack), proved on the opengl3 harness
(Xvfb + llvmpipe, the Compatibility renderer - NOT what the Mac draws; that is the point of the pack).
There is no "before": the pack did not exist.

- `01_after_pause_menu_verify_button.jpg` - the pause menu at 720 lines, **Verify pack** beside Settings.
- `02_after_verify_sheet_opengl3.jpg` - the contact sheet one run writes (ten cameras, fps / GPU ms / tris / draws / luminance under each).
- `03_after_end_card_1080.jpg` - the card at the end (HUD and player back), at 1920x1080.
- `04_after_pack_01_street_noon.jpg`, `04_after_pack_02_street_night.jpg`, `04_after_pack_10_pier_night.jpg` - three of the ten pictures as the pack saved them (no HUD, no progress line).
- `05_after_report_opengl3.txt` - the report the run wrote (llvmpipe, so ~0.2-2.5 fps).
