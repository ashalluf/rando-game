# Fashion district stills (wt/fashion-district)

"before" ones are the same eyes with `FASHION=0`.

- 05 / 06 - the same alley from above (EYE 3331,32,795,-180,-42).
- 07 - along a district pavement (EYE 3256,1.7,1019.5,-90,-6).
