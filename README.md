# drive-weight stills (wave 9)

Probe scene `tools/drive_weight/probe.tscn` with `SHOT=` (opengl3, a bare ground plane, not the city).
Each image: left DRIVE_SUSPENSION=0 (main), right the new suspension and body lean.

- 01_sedan_hard_stop: the deepest nose dive of a full stop from 100 km/h, side on (1.4 deg -> 3.0 body + 2.2 drawn).
- 02_suv_hard_stop: the same for the SUV (1.8 -> 3.0 + 2.2).
- 03_sedan_full_lock: two seconds into a full-lock corner at 15+ m/s, from behind (roll 2.9 -> 4.2 + 3.6 drawn, leaning out).
- 04_suv_full_lock: the same for the SUV.
