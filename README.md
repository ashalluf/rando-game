# shots/rc5-backyard-pool

New reference camera `backyard_pool` (tools/refcams/cameras_w8.json): a valley suburb back yard on a
Saturday at 15:00 clear, from the patio over the pool south toward the front range. opengl3
(Compatibility) stills from `tools/refcams/refcams.py` / `tools/glshot/block_shot.tscn`, not the
Mac's Forward+.

- `02_after_first_pass_backyard_pool.jpg` - first pass.
- `03_after_backyard_pool.jpg` - the branch: the traced pool (water below the coping behind a mosaic
  band, the tank refracted, the yard mirrored), the built fence (boards, cap, kickboard, weathering),

- `05_pool_crop_before_over_after.jpg` - the pool, before over after.
- `06_after_pool_closeup_traced_tank.jpg` - looking down into the pool: tile band, floor stripe,
