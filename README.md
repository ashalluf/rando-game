# shots/rc5-power-plant-dusk

The new wave-8 refcam `power_plant_dusk`: the coastal power plant at 18:50 clear from the wet sand
north of it (eye -713, 1.7 agl, 1115; yaw -141, pitch 9, fov 66). opengl3 stills from
`tools/refcams/refcams.py` (`REFCAMS_JSON=tools/refcams/cameras_w8.json`). "Before" is the same
build with `RC5_POWER_PLANT=0` (the A/B switch puts the plant exactly as on main).

- `01_before_power_plant_dusk.jpg` - main's plant: flat cream window slabs z-fighting the wall,
  moon-grey unlit cladding, lamp dots that light nothing.
- `02_after_power_plant_dusk_round1.jpg` - round 1: the plant's lamps light it, framed glazing in
  lit / dark bays.
- `03_closeup_before_over_after_round1.jpg` - the halls close up (an earlier eye), before over after.
