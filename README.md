# shots/rc5-marine-evening

Refcam `marine_evening` (tools/refcams/cameras_w8.json): the marine layer's evening fog bank at 18:30,
weather marine, from the beach-town sand at (-683, 1.7 AGL, 820) looking south-west (yaw 127, pitch 5,
fov 55) past a lifeguard tower. opengl3 refcams unless named. Before = the same row with
`MARINE_EVENING=0` (= main's look).
