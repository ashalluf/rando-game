# garage-drive-in stills (first batch)

Multi-storey car park downtown ("CIVIC PARK", block (22,-7), 6 decks), opengl3 / Compatibility
renderer (not the Mac's Forward+), 1280x720, 15:00. Sequence 02-06 is one real drive: the player in
a sedan, driven by tools/car_park/autopilot.gd with the player's own controls, from the street to the
roof (146 s of game time). Weather rolled to rain during the drive.
