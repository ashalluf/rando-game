# golden-hour-review stills

Six views x 17:00, 17:30, 18:00, 18:30, 19:00, 19:30 (tools/golden_hour/cameras.json, opengl3 through
tools/refcams). Each strip: main (top, GOLDEN_HOUR_REVIEW=0) over this branch (bottom), numbers under each
frame (luminance p5/p50/p95, saturation, sky/ground median ratio, warmth R/B, orange share).

- 01 coast (the Esplanade looking south), 02 beach toward the sun, 03 downtown aerial from the SW,
  04 the front range from 260 m, 05 Flower at Olympic looking north, 06 Olympic looking west into the sun.
- 07/08 the aerial at 18:00 before / after; 09/10 the beach toward the afterglow at 18:30 before / after.
- numbers.txt: every shot, before -> after, with the frame cost (tris %, draws; run-to-run traffic noise).
