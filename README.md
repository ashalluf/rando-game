# street-signs stills (branch wt/street-signs)

The street's signs as real models (StreetSigns / SignKit / SignFont, shaders/street_sign.gdshader).
All opengl3 (the Compatibility renderer, what the web build draws), 1280 px. Before = the same
build with `STREET_SIGNS=0` (the old cylinder stop sign, box plates with TextMesh names).
