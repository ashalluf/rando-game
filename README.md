# historic-core stills (wt/historic-core)

Downtown's historic core: beaux-arts banks and offices on Spring St and Main St (2nd to 9th St).
opengl3 (Compatibility) renders; "before" are city stills (still_shot.gd), "after" first batch are
block_shot.tscn renders of the same streets (the FULL blocks alone; no far city past them).

- 03_before_main_south_noon.jpg - Main St south, before
