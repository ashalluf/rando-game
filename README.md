# shots/rc-freeway

The freeway reference camera (the 110 by downtown, 13:00 clear), before (main e5bb9e4) and after.

- 01 / 02: the refcam (opengl3 1280x720): the deck nearly empty at noon -> per-lane traffic fill.
- 03 / 04: the deck close up (block_shot): moire rings from the tining and a ladder of black tiles for the rumble strip -> rounded tining that fades early, milled scoops.
- 05 / 06: the outer barrier at a bend: a dashed crack between deck segments -> mitred segment ends.
- 07: the after refcam from another run (traffic differs run to run: here a semi sits just ahead).
- 08: all ten refcams, before (FREEWAY_FILL=0 FREEWAY_LOOK=0, = main) over after: only the freeway moves.
- 09: after, the shoulder and barrier close up (scoops, mitred barrier, joints).
