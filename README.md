midtown auto row, 11:00 clear, from the kerb at the lot's south end looking north-east. opengl3
(Compatibility), not the Mac's Forward+.

- `03_after_auto_row_final.jpg` - final: the same, the box cars as shadow-only proxies for the real bodies. 6.08 M / 3,269.
