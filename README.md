# shots/rc5-crash-closeup

- `01_before_crash_closeup.jpg` - main's crash code with the new staging: the bonnet swung wide open over a black engine bay, a flat-topped full-width crush with torn teeth at the wing, the bumper hanging like cloth, the lower grille standing whole in front of the crushed nose (CarCloseup's bumper-band copy), no fluids, no steam.
- `02_before_kit_pole55_carshot.jpg` - the same hit on the car alone (car_shot.gd `DAMAGE=pole55`, CRASH_AFTERMATH=0).
- `03_after_kit_pole55_carshot.jpg` - after: the nose bent into a V round the pole, the bonnet popped and buckled, the bumper wrapped (not hanging), coolant and oil run out, radiator steam.
